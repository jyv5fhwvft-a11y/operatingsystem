BDS Phase: UEFI locates the EFI System Partition (ESP) and finds the bootloader.
SEC Phase: CPU wakes up, sets up temporary RAM, and verifies PEI integrity.
OS Loader: bootmgfw.efi runs winload.efi, which calls ExitBootServices().
DXE Phase: Hardware drivers are loaded and Boot Services are initialized.
PEI Phase: Main system memory (RAM) is initialized and HOBs are created.
