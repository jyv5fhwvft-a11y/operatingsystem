The MBR Inspector

Type a command below to view the raw hexadecimal bytes of the Master Boot Record and see the Disk Signature in memory.

user@cs301-machine: ~
Welcome to the Windows MBR Inspector. Type hexdump -C /dev/sda -s 496 -n 16 and press Enter to view the Disk Signature.
user@cs301-machine:~$
