The wait() Operation

When a thread wants to enter the Critical Section, it calls wait(S). This decrements the semaphore value (S = S - 1). If S becomes negative, it means the resource is taken, so the thread is added to the Blocked Queue.

2

The signal() Operation

When a thread finishes its work, it calls signal(S). This increments the semaphore value (S = S + 1). If S is still 0 or negative, it wakes up a thread from the Blocked Queue and moves it to the Critical Section.

3

Atomicity

Notice how the counter can never be modified by two threads at the exact same time. The OS guarantees that wait() and signal() are atomic—they happen entirely or not at all. This prevents race conditions.
