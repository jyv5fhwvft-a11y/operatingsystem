The UEFI River Flow

Watch how UEFI passes control through its phases, loads the Windows boot manager, and finally hands the hardware over to the OS.

SEC Phase

Reads GPT · Mounts ESP at fs0:

Windows Kernel

Calls ExitBootServices() → Full Control

💡 The Magic of UEFI

UEFI doesn't read 512-byte sectors like BIOS. It reads files from a FAT32 partition (the ESP), runs them like standard applications (.efi), and provides a rich API (Boot Services) until the OS is ready to take over.
