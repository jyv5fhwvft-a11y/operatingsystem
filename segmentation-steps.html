The CPU generates a logical address

The program asks for a specific variable. It provides a pair of numbers: the Segment Number (e.g., Segment 1 for Data) and the Offset (e.g., Offset 04, meaning the 4th byte into that segment).

2

Look up the Segment Table

The Memory Management Unit (MMU) looks at the Segment Number and finds the corresponding row in the Segment Table. It grabs the Base and the Limit.

3

Check the Limit (Security Check)

The MMU checks if the Offset (04) is smaller than the Limit (1000). If the program tries to read Offset 1500, the MMU throws a Segmentation Fault (SIGSEGV) because the program is trying to read outside its allowed boundary.

4

Calculate the Physical Address

If the offset is safe, the MMU adds the Offset to the Base. (e.g., Base 0x9000 + Offset 04 = Physical Address 0x9004). The CPU can now fetch the data from RAM!
