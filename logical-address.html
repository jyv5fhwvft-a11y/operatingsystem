Logical Address Space

The virtual memory illusion. How programs are compiled to start at address 0, and how the MMU translates that to physical RAM.

The Definition

The Logical Address Space (or Virtual Address Space) is the set of all addresses generated by a program's CPU instructions. Programs are compiled assuming they own the entire memory and start at address 0. The Memory Management Unit (MMU) intercepts these logical addresses and translates them into physical addresses in actual RAM using methods like Base/Bound registers, Paging, or Segmentation.

🍎 The 5th Grader Analogy
Imagine a massive hotel. Every guest is given a room key that says "Room 100". The guest thinks they are in the 100th room on the first floor.

However, the front desk manager (the OS) secretly assigned them to Room 504 on the 5th floor. When the guest asks for "Room 100", the front desk quietly redirects them to 504. They are living in a logical illusion!
Guest Key
Logical: 100
🛎️
Actual Room
Physical: 504
⚙️ The Technical Analogy
The CPU generates a Logical Address (e.g., 0x0010). It sends this to the MMU.

The MMU takes the Base Register (e.g., 0x4000) and adds it to the Logical Address: 0x4000 + 0x0010 = 0x4010. This is the Physical Address sent to the RAM chip. If the logical address exceeds the Bound Register, it throws a Segmentation Fault.
CPU
Logical: 0x10
➔
MMU
Base: 0x4000
➔
RAM
Physical: 0x4010
