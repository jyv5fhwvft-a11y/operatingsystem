Semaphore

A synchronization primitive used to control access to shared resources and prevent race conditions in concurrent systems.

The Definition

A Semaphore is an integer variable that is accessed only through two standard atomic operations: wait() (or P) and signal() (or V). It is used to manage concurrent processes by acting as a counter for available resources (Counting Semaphore) or as a simple lock (Binary Semaphore / Mutex).

🍎 The 5th Grader Analogy
Imagine a Nightclub Bouncer with a clicker. The club has a strict capacity of 3 people (the Semaphore value).

When a person arrives, the bouncer clicks the counter down (wait()). When the counter hits 0, the club is full, and new people must wait outside in line. When someone leaves the club, the bouncer clicks the counter up (signal()), allowing the next person in line to enter.

⚙️ The Technical Analogy
A semaphore is an integer variable in the kernel. The OS guarantees that checking and modifying this integer is atomic (using hardware instructions like TestAndSet).

wait(S): Decrements S. If S < 0, the calling thread blocks (goes to sleep).
signal(S): Increments S. If S <= 0, it wakes up a blocked thread.
wait(S)S = S - 1
if (S < 0)Block thread in queue
signal(S)S = S + 1
if (S <= 0)Wake up a blocked thread
