The CPU Generates a Logical Address

The program asks for data at a specific logical address (e.g., 150). It assumes it owns the whole machine and starts at 0.

2

The MMU Checks the Bound

The Memory Management Unit checks if the logical address is smaller than the Bound Register. If it is larger (e.g., 1500), it throws a Segmentation Fault and kills the program.

3

The MMU Calculates the Physical Address

If the check passes, the MMU adds the Base Register to the Logical Address (4000 + 150 = 4150). This new physical address is sent to the RAM chip.
