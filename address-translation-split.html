The Address Split & Translation

How the CPU's request is split into a VPN and Offset, and reassembled into a Physical Address.

🏢

The Apartment Analogy

Think of a Logical Address like "Apartment 40, Room 5".
The VPN (Virtual Page Number) is Apartment 40.
The Offset is Room 5.
When the mail clerk (MMU) looks up Apartment 40 in the directory (Page Table), they find out it's actually Building B, Suite 12 (Physical Frame). The new address becomes Building B, Suite 12, Room 5.

1. The CPU generates a 32-bit Logical Address
The program requests a variable. To the program, this is a single, large address.
Logical Address 0x0040A005
2. The MMU Splits the Address
The hardware chops the address into two pieces. The top bits identify the Page (Apartment). The bottom bits identify the Offset (Room).
VPN (Apartment) 0x0040A
Offset (Room) 0x005
3. The VPN indexes into the Page Table
The MMU takes the VPN (0x0040A) and finds its row in the Page Table to see where it actually lives.
VPN (Virtual Page)PFN (Physical Frame)
0x004090x00B12
0x0040A0x01A05
0x0040B0x00C44
4. The MMU Replaces the VPN
The MMU swaps the Virtual Page Number for the Physical Frame Number (PFN). The Offset (Room 5) stays exactly the same!
Physical Frame (Building B) 0x01A05
Offset (Room) 0x005
5. The Physical Address is sent to RAM
The pieces are glued back together. This is the real location in the RAM chip where the data lives.
Physical Address 0x01A05005
