Knowledge Base Master Map

This is the official architecture reference for the CS 301 Knowledge Base. Use this document to track completed topics and ensure consistency when adding new learning models.

PART 1 The 9-File Architecture

Every topic must be built using this exact 9-file structure. If a new learning model is discovered, a new file must be created for every topic below.

01 [topic].html (Master Hub: Definition + Analogies)
02 [topic]-steps.html (Interactive Step-by-Step)
03 [topic]-mindmap.html (Interactive Node Map)
04 [topic]-infographic.html (Visual Flowchart)
05 [topic]-sandbox.html (Feynman "What If?" Simulator)
06 [topic]-puzzle.html (Feynman Drag-and-Drop Game)
07 [topic]-terminal.html (Feynman OS Shell Inspector)
08 [topic]-flashcards.html (Feynman Rapid-Fire Quiz)
09 [topic]-spot.html (Feynman Failure Diagnosis)
