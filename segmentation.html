Segmentation

Dividing memory into logical, variable-sized chunks like code, stack, and data.

The Definition

Segmentation is a memory management technique where a program's virtual address space is divided into variable-sized blocks called segments. Unlike paging, segments are not fixed-size; they represent logical units of the program, such as the code, the heap, and the stack.

🍎 The 5th Grader Analogy
Imagine your school building. Instead of making every room exactly the same size (which wastes space if you need a giant gym), the school is divided into different sized rooms based on what they hold.

The gym is a big room. The library is medium. The principal's office is small. In memory, a program is built the same way: the code gets a big segment, the stack gets a medium segment, and the global variables get a small segment.

⚙️ The Technical Analogy
The CPU sees memory as a set of logical segments. Each segment has a Base (where it starts in physical RAM) and a Limit (how long it is).

When the CPU tries to read a memory address, it checks the Segment Table, finds the segment's base, and adds the offset. If the offset is bigger than the limit, it throws a Segmentation Fault.
Segment Table
Seg 0 (Code) : Base 0x4000
Seg 1 (Data) : Base 0x9000
Seg 2 (Stack) : Base 0xB000
