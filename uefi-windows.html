Windows UEFI Boot

The modern 32/64-bit firmware interface. From pressing the power button to the Windows login screen using GPT and EFI files.

The Definition

The UEFI (Unified Extensible Firmware Interface) boot process is the modern standard for initializing hardware and loading an OS. Unlike the legacy BIOS, UEFI runs in 32-bit or 64-bit mode from the start, uses the GPT (GUID Partition Table), and loads `.efi` executable files from a dedicated EFI System Partition (ESP) rather than relying on 512-byte MBR sectors.

🍎 The 5th Grader Analogy
Imagine a Modern Smart Home.

Instead of an old fuse box that has to test every wire one by one (Legacy BIOS), you have a central smart hub. As soon as power hits, the hub wakes up, checks the security system (SEC), turns on the lights and HVAC (PEI/DXE), and brings up a menu on the wall (BDS). You tap "Open Windows," and the smart home instantly launches the Windows app from the cloud (EFI partition)!

⚙️ The Technical Analogy
UEFI boots through distinct phases: SEC (Security), PEI (Pre-EFI Initialization), DXE (Driver Execution Environment), and BDS (Boot Device Selection).

Once BDS selects the boot device, UEFI reads the GPT, finds the EFI System Partition (ESP), and executes bootmgfw.efi. Windows BOOTMGR then reads the BCD, loads winload.efi, and finally calls ExitBootServices() to take full control of the hardware.
